Project Reference List

Capstone bibliography for formulas, clinical guidance, medication content, source charts, and pilot-study methods.

Evidence Standard

Prioritize peer-reviewed literature from PubMed/PMC, professional society guidelines, FDA/DailyMed labels, NCBI Bookshelf support summaries, and manufacturer materials only when device-specific chart data are needed.

Reference Workflow

  • Add every new clinical, pharmacology, formula, manufacturer, or research-methods source used in the project to this page.
  • Use PubMed/PMC indexed research, AmSECT/STS/SCA/AABB guidance, FDA/DailyMed labels, and NCBI Bookshelf support summaries before general web pages.
  • Use manufacturer sources for cannula charts, source curves, device specifications, and product-specific flow/pressure data.
