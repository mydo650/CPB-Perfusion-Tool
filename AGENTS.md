# Repository Workflow Instructions

This working copy has two Git remotes with intentionally different purposes:

- `internal`: the complete private CPB Perfusion Tool project.
- `origin`: the restricted public GitHub Pages demo.

Before editing files, committing, pushing, or deploying, ask the project owners whether the requested change targets the private internal project, the public demo project, or both. If both are requested, confirm which files and features are approved for the public demo.

Do not push the full internal project to `origin`. Do not publish a page merely by hiding its navigation link; the public deployment must contain only explicitly approved demo files. Do not delete files or change GitHub Pages settings without an explicit request.

See `PROJECT_NOTES.md`, section "Repository Separation And Change-Control Policy," for the complete policy and repository URLs.
