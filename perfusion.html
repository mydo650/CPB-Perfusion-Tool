Support Material

BSA
Mosteller: √((height cm × weight kg) / 3600). If height is missing, Costeff: ((4 × weight kg) + 7) / (weight kg + 90).
Flow Window
1.6 to 3.0 L/min/m² × BSA, with an indexed flow map shown in L/min
DO2i
((Hgb × 1.34 × SaO2 fraction) + (0.003 × PaO2)) × 10 × effective cardiac index
Required CI / Flow / Hgb
Rearranged from the DO2i equation using the selected target and current oxygenation inputs

Variable definitions: Hgb = hemoglobin, Hct = hematocrit, SaO2 = arterial oxygen saturation, PaO2 = arterial oxygen tension, CI = cardiac index. If pump flow is entered, effective CI = pump flow / BSA. If Hgb is not entered, the tool estimates Hgb as Hct / 3.

Decision-support calculator for simulation use. Confirm protocol-specific targets and rounding requirements before clinical use. Aim to maintain DO2i above the selected target when clinically appropriate.
